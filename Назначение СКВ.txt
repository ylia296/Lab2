GitHub — крупнейший веб-сервис для хостинга IT-проектов и их совместной разработки.
Веб-сервис основан на системе контроля версий Git.
Ознакомиться с документацией по работе с GitHub можно на сайте GitHub Help.

Системы управления версиями (СКВ) предназначены для сохранения истории изменений
файлов проекта и возможности возврата к любой предыдущей версии.
Распределённая СКВ Git позволяет каждому разработчику иметь полную копию репозитория.
